# design/brand/

Logo and project name for **Init** (brand name D-007). **Status: Proposed (s14, 2026-11-02), not approved.**
Nothing here is used by the app or the device until the owner picks a logo and a full name.

| File | What |
|---|---|
| `build-logos.mjs` | Draws the logos as SVG from `../tokens.json`; letters are plain strokes, so no font licence (D-010) |
| `logo-a-*.svg` | A: `init` wordmark, both i-dots in the heat accent |
| `icon-b.svg`, `logo-b-*.svg` | B: app icon (an `i` drawn as a thermometer) plus wordmark; the icon doubles as PWA icon and favicon |
| `logo-c-*.svg` | C: heat index gauge in the four PAGASA band colours (D-019) above the wordmark |
| `preview.html`, `capture.mjs`, `preview.png` | All three on light and dark, and at 32 px and 16 px |

## Full name proposals
1. **Init: Indoor Heat Index Tracker** — An IoT-Based Classroom Heat Index Monitoring System
   (IN-door + Index + Tracker; "init" is also the programmer's word for *start*)
2. **Init: Indoor Index Tracker** — Real-Time Heat Index Monitoring for Classrooms During El Niño
3. **Init: Indoor Heat Index Tracker** — A Low-Cost ESP32 Device and Web App for Monitoring Classroom Heat Stress
