1Before you start

An admin is a person who can change how the device works. Only a few people have the password.

When you press Save changes, the new settings are stored. The device picks them up within about a minute. You do not need to touch the device.

Everyone can look at the readings. Only admins can change the settings.

2Room

What it does

It tells people which room the device is in right now.

When to change it

Only when you move the device to another room.

Steps

  1. Sign in on the Admin page.
  2. Under Room, type the new name, for example Room 204.
  3. Press Save changes.
Type a room name only. Never type a person's name. Old readings keep their old room.

3Device health

What it does

It shows how the device is doing right now. It is only for looking. You cannot change anything here.

When to look at it

When readings are missing, or the page says Offline. It helps you find out why.

What each line means

LineWhat it tells you
Wi-Fi signalHow strong the connection is. Good and Fair are fine. Weak can make readings go missing.
Last restartWhy the device last started. See the list below.
FirmwareThe version of the program on the device. Tell it to the person who set up the device when you ask for help.
Last reportWhen the device last sent a reading. Late means more than 2 minutes ago.

If the signal is Weak

Move the Wi-Fi hotspot closer to the device, or the device closer to the hotspot. Then look again after a few minutes.

ExampleThe number is in dBm, and closer to 0 is stronger. −58 dBm is stronger than −81 dBm.

If you see a restart reason

It saysWhat to do
Power onNothing. Someone plugged the device in.
Reset pin, Software restartNothing, if someone pressed the reset button or updated the device.
Power dippedThe power was too low for a moment. Check the cable and the power bank.
Stopped responding, CrashThe device froze and restarted by itself. If it keeps happening, tell the person who set up the device.
Not reported yet means the device has not sent its health. This is normal until it gets its next update.

4Reporting interval

What it does

It is how often the device sends a reading. 60 means one reading every 60 seconds.

When to change it

Keep it at 60 when the device runs on a power bank. A power bank can switch itself off if the device uses very little power for too long. A longer time is fine only on a wall charger.

Steps

  1. Under Device, find Reporting interval.
  2. Type a number of seconds between 60 and 3600.
  3. Press Save changes.
ExampleWall charger, and you only need a reading every 5 minutes: 5 × 60 = 300.

5Temperature and humidity offsets

What it does

An offset fixes a sensor that reads a little too high or too low. It is added to every new reading.

When to change it

Only after you compare the device with a thermometer you trust. If you have not done that, leave both at 0.0.

Steps

  1. Put the trusted thermometer next to the device, out of the sun.
  2. Wait 30 minutes.
  3. Write down both numbers. Do this 3 times, 5 minutes apart.
  4. For each pair, subtract: trusted number minus device number.
  5. Take the average of the 3 answers.
  6. Type it in Temperature offset and press Save changes.
ExampleThe device says 31.0 °C. The trusted thermometer says 30.2 °C. The offset is 30.2 − 31.0 = −0.8.

Humidity works the same way, with the trusted humidity number.

An offset changes new readings only. Old readings stay as they were.

6Heat alerts

Alerts are coming in a later step. These settings are saved now but nothing is sent yet.

The levels

These names and numbers are from PAGASA. They use the heat index in °C.

LevelHeat index
Caution27 to 32
Extreme caution33 to 41
Danger42 to 51
Extreme danger52 and up

Alert at heat index

The heat index where an alert is sent. 42 means an alert when the room reaches Danger.

Quiet period

After an alert, no new alert is sent for this many minutes. With 60, you get at most one alert an hour.

Steps

  1. Under Heat alerts, type the heat index for Alert at heat index.
  2. Type the minutes for Quiet period.
  3. Press Save changes.

7If something looks wrong

It says "Not saved"
A number is outside its range. The range is under each name. Fix the number and press Save again.
It says "Not an admin"
You signed in with an account that is not an admin. Sign out and use the admin account. Ask the person who set it up.
The page says Offline
No reading came in for 2 minutes. Check that the device has power and the Wi-Fi hotspot is on. It comes back by itself within a minute or two.
