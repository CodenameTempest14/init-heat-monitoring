# tools

Project scripts (Node). `phase-report.mjs` prints the status line and Phase Progress table, `continuation-prompt.mjs` writes the next-session prompt, `check-readmes.mjs` checks every folder has a README, `db.mjs` runs the Supabase CLI against the test or live project (see `supabase/README.md`; the access token is read-only, so `db query` can read but a data change on live is run by the owner in the dashboard SQL Editor), `secret-scan.mjs` checks the staged diff for the secret values in `.env` and `secrets.h` and exits 1 on a hit (run it before every commit; tests in `tests/secret-scan.test.js`), `device-key.mjs` makes the device key in `.env` and stores only its SHA-256 in a project (the access token is read-only, so it writes through the database password). `anon-probe.mjs` acts as a stranger with only the public key (P04-06): reads must work, writes and the device key hash must be refused, and a marker row must not exist afterwards; safe on a running system (`node tools/anon-probe.mjs`, or `<url> <key>` for another project; exits 1 on a failure). Do not use the backend tests for this: they wipe init-test.
