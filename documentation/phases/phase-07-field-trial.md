# Phase 7 — Field trial and hardening

**Objective:** Prove the whole system works in a real classroom for a week, and fix what that shows.
**Entry criteria:** P06 closed.
**Exit criteria:** A week of readings with no unexplained gaps; owner signs off.
**Features:** none new. Model: Opus 5.5.

Checklist markers: see phase-01.

- [ ] P07-01 Enclosure built; DHT22 placed away from the ESP32 and the power bank
- [ ] P07-02 One week running in a real room; every gap in the data explained
- [ ] P07-03 Readings compared with a reference thermometer and hygrometer; calibration offset set
- [ ] P07-04 Real runtime on the ROMOSS bank measured and the estimate corrected
- [ ] P07-05 Final security review (keys, row-level rules, admin routes)
- [ ] P07-06 Accessibility check (contrast, text size, screen reader basics)
- [ ] P07-07 Owner sign-off
