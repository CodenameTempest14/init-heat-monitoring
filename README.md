# Init

*Know the heat before it hits the classroom.*

Working name for the classroom heat index monitor: a power-bank-powered ESP32 device (DHT22 + OLED) that sends temperature and humidity to a public web app (PWA on Supabase and free static hosting), which shows the heat index for one room.

- `CLAUDE.md`: rules for working here (carried over from Ad Astra)
- `hardware/`: device schematic (Rev B, drafted, not built)
- `documentation/`: decisions, phases, reports, current state
- `tools/`: phase report and continuation prompt scripts
